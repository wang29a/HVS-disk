# 五项执行顺序与已完成离线结果

更新：五权重扫描已完整完成，三轮齐全、待补为零，最终数字和两种横轴曲线见 [WEIGHT-SCAN-RESULTS.md](WEIGHT-SCAN-RESULTS.md)。后续三臂拓扑驻留已接续。下文保留离线分析结果与原执行协议。

前三项已按顺序在本地完成，node3 只读取所需文件和数据切片。两数据集各抽 256 条既有报告查询。距离使用 float64 欧氏距离，贡献为 α·d_image/(α·d_image+(1−α)·d_text)，不改变现有距离目标。

固定参考集的平均贡献均衡点：Laion 0.497，OpenImages 0.307。Laion 参考集取五个权重 GT 的逐查询去重并集；OpenImages 只有现有 mixed-GT，因此后者是同一邻居集合上的重算，不能称为五个固定权重的真实近邻结果。均衡点是样本邻域的描述，不是唯一的全局距离归一化参数。Laion 一条查询（原 ID 245）的十个 GT 邻居双空间距离均为零，贡献无定义，计入排除数量；有效贡献查询为 255 条。
