# α 端点过滤与原生缓存对照

远端目录是 `/mnt/nvme3/wz/hvs-disk-build-20261027/experiments/graph-filter-followup-20261110`。两个 tmux 会话使用同一把全局实验锁。 `hvs-graph-filter-20261110` 执行 OpenImages；`hvs-graph-downstream-20261110` 等待它结束，然后准备 CC3M、复做端点对照，再执行 CC3M 和 Laion 的同批次系统对照。用 `status.json`、`downstream.json`、`cc3m/status.json` 和 `native/status.json` 区分等待、计时和结束。

CC3M 首次准备因新建目录缺少父路径退出。修复已通过 node3 上的目录及二进制前置校验。原生对照已接着执行，CC3M 端点由 `hvs-cc3m-endpoint-retry-20261110` 等同一把锁补排，进度在 `cc3m-retry.json`。

OpenImages 固定 α=1、原 M=2 邻居记录、归档 Starling 顺序、入口、PQ、X-only 坐标文件、X 空间 GT 和 256 MiB 共享拓扑缓存。开关只控制查询时是否检查每条边的活动区间。过滤开启时，已与上批归档的返回 ID 和距离逐字节对齐。绕过过滤时，从原始坐标独立复核输出距离，从 X GT 重算召回。筛选遍历发现率统计进入访问集合的真邻居，候选覆盖率统计最终送去精排的真邻居。二者只在单次回放诊断中统计。后续边级审计固定 `L=60` 并回放两组的展开序列，核对这些计数。

CC3M 复用 M=2 的拓扑与 Starling 顺序，两组坐标分别是 1024 维和 768 维。用 X 构建独立 Vamana 图，R=40、Lbuild=100，复用双空间的 X 侧 PQ。准备阶段限制在 NUMA 3 的两个空闲物理核。先验证已有候选 GT，缺少匹配的纯 X GT 时才做穷举。独立图和双图 X-only 共享物理坐标文件，第三组保留双图和双向量执行。使用三组各自实测曲线对齐 X 空间 90%、95%、98% Recall@10，只报告覆盖的目标。

系统对照使用原生耦合 Baseline、Merge 关缓存和 Merge 开缓存。CC3M 复用 mixed-α 及配套 GT，Laion 复用 α=0.5 及配套 GT。Baseline 搜索库和调用参数沿用归档版本，计时驱动统一使用完整 1,000 查询预热和外部服务时延的 p95。Merge 的共享缓存开关做输出一致性校验。报告按工作点给出总后端页数和各 reader 的阶段时间，后端页数为软件计数。

正式测量固定 NUMA 3、四个物理核心、四线程、单线程 BLAS、beam 4、K=10。轮换方案顺序，三个重复，每点至少 10 秒。主机写流量和剩余读流量按测量时间段筛查，异常尝试保留。p95 报告最近的实测召回，其他指标在每个重复的实测区间内插值。每个子目录的 `analysis/progress.json` 和 `analysis/measurements.json` 记录已接收的曲线和原始计时。

## OpenImages 筛选结果

这批单次回放用于确定 L 和诊断候选。正式吞吐与时延另见测量记录。

| L | 区间过滤 | 遍历发现率 | 精排候选覆盖率 | 最终 Recall@10 |
|---:|---|---:|---:|---:|
| 36 | 开启 | 92.65% | 91.06% | 90.97% |
| 36 | 绕过 | 94.14% | 92.35% | 92.26% |
| 60 | 开启 | 95.15% | 94.60% | 94.52% |
| 60 | 绕过 | 96.26% | 95.63% | 95.56% |

筛选点内插，95% 召回对应的 L 从约 63.8 降到 53.5，约降 16%。独立单空间图上批约为 35.5，因此绕过查询期过滤后仍有搜索深度差距。筛选中的召回差异可以复现，正式 QPS 和延迟以三次通过筛查的计时为准。
