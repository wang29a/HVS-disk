# High-concurrency diagnosis and topology-resident control

Frozen before execution, 2026-11-15. This is a diagnosis of the completed native-versus-compact sweep, not a new tuning run or a claim that adding DRAM is a free optimization. Existing source graphs, PQ, GT, train/report cohorts, original ordering, and 95%-recall weighted-pages-rule brackets are read-only.

Run OpenImages mixed-alpha and Laion2M alpha=0.5 first. Threads=4/16/32, NUMA3, three interleaved repetitions, one global queue lock, 10 measured seconds per raw point after identical executable warm-up. Methods are native TXY on SSD, compact no-sidecar T|XY on SSD, and the same compact executable with topology resident in DRAM and coordinates on SSD (`medium=topo`). The native path reads an exact vector for every expanded node from coupled pages, so topology-only residency is a diagnostic control of the compact path, not a separately optimized native implementation. No persistent shared cache and no Starling changes.

Use exactly the existing tune-frozen 95% weighted-pages brackets. Do not choose L/r using report latency. Native and compact may have different configurations as already frozen; compact SSD/topo must use identical jobs, return IDs/distances and traversal traces. Topology-resident must submit zero topology backend pages and preserve coordinate requests, expansions, PQ work and rerank candidates. Validate all 500 report queries for compact SSD/topo before timing, including ordered batches and candidates (trace mode); both routes undergo the executable's float64 distance check. A correctness failure stops dependent timing, without parameter changes.

The common memory ceiling remains the supplemental 4 GiB used in the completed sweep, including resident topology. Record peak RSS and resident bytes rather than claiming equal actual allocation. Retain the original 2 GiB evidence separately. Binding uses NUMA3 physical CPUs 72-95 first, then sibling CPUs 168-175 for 32 threads, as in the completed sweep; no run exceeds32 threads. Offline capture/build checks use at most2 cores and do not overlap timing on this NUMA node.

Collect QPS, mean/p95 latency, topology/coordinate submitted pages and wait microseconds, exact compute time, expansions, per-space PQ counts, rerank depth and peak RSS. Native reports coupled pages/reader time. The reader interval includes submission/wait; latency minus reader intervals is a residual, not pure CPU time. Save aligned /proc process CPU/fault/context-switch/read_bytes, device I/O counters, and CPU frequency snapshots every0.5s plus existing external-noise/NUMA guards. Device counters include other users and cannot alone identify process I/O; process counters and workload intervals are retained separately. Diagnostic runs use the same binaries and counter overhead as the prior sweep. No fine-timing source instrumentation is added.

Accept only actual NUMA-observed windows with the existing CPU/disk-write guards and RSS<=4GiB; retry at most3 times and preserve failed attempts. Guard failures become pending and block automated large A/B builds. Save raw p95 at each real configuration; do not interpolate tails. At frozen 95% brackets interpolate mean metrics using the original weights, then average3 repetitions. Also publish raw recall/configurations and each repetition; no extrapolation and no changing brackets if timing drifts.

Interpretation is conditional: topology residency removing the high-thread loss suggests topology I/O contributes; a loss persisting with zero topology reads points to coordinate I/O or execution overhead. Compare coordinate wait, process CPU and residual before attributing a mechanism. This experiment does not establish a fully equal-cache-budget production configuration or invalidate the four-thread results.

## Append: residency gate field correction, before timing

The first gate rejected identical binary traces because the OpenImages per-query JSON field named topology_pages counts backend submissions, unlike its aggregate graph topology_pages field. That field must change to zero with residency. Compare all other per-query fields, require all four trace files byte-equal, and retain the existing aggregate logical-page/work invariants plus zero topology submissions.
