# 2026-11-13：区间剪枝结果有效性复核

比较符补充：以下敏感性审计以 v2 的 LE（小于等于）为反事实，其中混有 LE 与论文严格小于约定的平局差别，不能全部归为上游分支缺陷。零斜率正右端项等情况在两种约定下都存在真正遗漏。详见 [来源与比较符核对](u-shape-20261113/SEMANTICS-PROVENANCE.md)。

已有实验运行和原始数字仍保留，但不能再将“距离公式、mergeIntervals 和量化已修正”等同于“区间剪枝语义已完整核验”。2026-11-13 发现原构图器的优势不等式仅处理严格正负的 slope/rhs，遗漏 slope=0 或 rhs=0；固定目标专用化把该问题放大，统一图也存在边界敏感情况。

以下是对最终浮点图的全量反事实审计，不是当年构图时的候选比较日志。每条边只计一次潜在敏感性，邻居对考察两个方向，并要求有活动区间重叠。最终反向插入边可能未重做剪枝，因此潜在边不能直接称作“确实因 bug 多留的边”，更不能把比例当成性能误差。

|---|---:|---:|---:|---:|

这些图都不能据此被认定为“不受影响”。使用它们的过滤开关、权重扫描、三臂和拓扑驻留等定量机制结论标为**待修正图复核**。不把这些结果删除，也不把格式正确、距离正确或三轮计时完成当作已经排除了构图语义问题。其他图／数据集没有经过本审计，不能从此表推断它们安全或有同样的受影响比例。

U 形 v1 的三张专用图明确排除作为有效专用图对照；旧统一图上的 46%/38% 两端额外展开量也暂不作为修正后结论。没有进入 SSD 路由。

修复与重建先限于原 2M 子集，执行 [v2 协议](u-shape-20261113/PRUNING-V2-PROTOCOL.md)：统一区间求解补齐零系数；专用图改用直接固定距离邻域剪枝；通过原语、真实 C++ 成员函数、暴力参考和小图穷举搜索核验后，重建统一图并收集真实调用与区间差异计数。计数只属于新运行，不能回填旧历史。中心 α=0.5 先过工作量与边预算检查，再构建两端；不扩大子集。

原始审计在 node3 的 `u-shape-20261113/stage2/analysis/`：`unified-final-audit-v1.json`、`prior-openimage-final-audit-v1.json`、`prior-laion-full-final-audit-v1.json` 与 `prior-unified-audit-summary.json`。新构建、冻结参数和测试记录写入独立的 `stage2-v2/`。既有 `source-manifest.json` 的 218 份归档身份保持不变，历史 Markdown 也保留为历史记录；本通知覆盖它们关于当前有效性的陈述。
