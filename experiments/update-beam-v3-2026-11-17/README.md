# 双空间更新执行器：束搜索与精确重剪默认值

本轮以用户已接受的 `c61836b95be711daf552d243b93f59bb57aacbfe` 为基线，在独立分支 `codex/dual-space-update-beam-v3` 开发。默认 `Options::exact_reprune=true`，即新点选边 exact、反向重剪 exact；PQ 保留为新点选边 exact、反向重剪 PQ 的对照。两种模式都在反向邻居未满时追加、满度时重剪，合并沿用同一重剪距离。候选搜索仍使用两套 PQ，没有将候选搜索改成全向量穷举。

查询遍历内核抽取自 `multigraph-20261113/scripts/multigraph.cpp::Engine::traverse`，原文件 SHA256 为 `0b2bdfac57a34aabd3bbc3d1b9426aa0fc907ff87186649b0194169abd0cc3b9`。新 `beam_search.h` 保留束宽4、InsertIntoPool及游标回退流程，通过回调接入已提交检查、统一页锁和操作私有缓冲。PQ评分复用原引擎的 aggregate_coords/pq_dist_lookup，查询精排复用上游 SIMD L2 距离。初始静态图上逐条核对500条查询、五个权重、三轮的Top10 ID和展开数；保留原引擎原文件作为参照，不改写参照路径。

插入没有查询权重，继续使用双空间Pareto候选排序；束提取、批量拓扑读取与批量PQ评分复用查询组件，每次最多展开4个节点。改变展开顺序后，不再要求增量图与旧版本逐位一致，质量门槛改用原G2：9万初始B图追加1万节点，对比10万全量B图，精确导航DRAM在alpha=0.1/0.5/0.9下达到95% ID召回的展开数增幅均不超过15%。初始图、全量图、坐标、子集、GT和原静态评估器按原身份校验后只读复用，两种模式的增量图必须重新生成。

生产路径的 coordinates() 返回操作私有向量缓存的const引用，命中不复制，首次取值只从私有页物化一次；查询精排直接使用已锁读完成的私有页指针。脱离上下文的坐标副本只通过明确命名的 copy_coordinates_for_audit() 提供，限离线审计。页缓冲可在线程内复用分配，Context销毁时丢弃全部文件/页映射，后续查询必须重新持锁读取；这不是跨查询数据缓存。每线程最多保留512个8KiB空闲缓冲，约4MiB。成功路径检查使用字符串字面量，失败时才构造异常消息。

批读每批最多48页，锁覆盖每页读入私有缓冲的完整I/O，完成后释放本批再处理下一批。48为TSan内部64把同时持锁上限保留余量；96页加外层操作锁的定向用例要在ASan/TSan下通过。不绕过页锁，不关闭死锁检测器。写入沿用已验证的锁外计算、页版本校验、原子入度预留和提交标记，磁盘格式不变。

run_preflight.py编译普通、阶段插桩、G1、G2与静态对照工具。首轮束搜索已对齐查询结果，但约5.7ms；源码和记录保留在runtime/preflight。缓冲分配复用、成功路径检查及48页批次修订保留在runtime/preflight-v2，作为本轮后续门槛的编译身份，不能混用首轮二进制。

run_gates.py独占原全局实验锁，先在Laion1万图上分别重跑1000次混合操作的G1，再对两种模式重建G2增量图，全部通过后执行ASan、TSan各两组G3。每组为4查询线程、2更新线程、600秒并发查询窗口、1000次总更新；若更新在插桩下落后，查询结束后排空的操作数与总秒另列。查询整体及500查询滑窗的保守召回下界均须不低于93%，并独立重算结构和入度。插桩覆盖新执行器、剪枝、驱动和Linux reader，不涵盖所有预编译支持库与外部依赖。

复测使用同一180万B图及后续1000点、NVMe3上的工作拓扑和坐标页、CPU72–75、NUMA3。四线程纯插入吞吐与阶段分解分别报告PQ和exact，OdinANN复用其冻结原生单空间索引和未修改源码，在同机同盘重新测量。阶段插桩通过编译开关启用；其图与快照要在同一新执行器的单线程重放中与未插桩版本一致，不把该检查当作与旧搜索顺序的逐位要求。索引准备、加载、GT、审计、JSON输出和fsync不计入插入计时。

本轮不启动E1，不自动恢复旧队列。所有门槛和性能复测完成后汇报并等待确认；确认后才用定版执行器在新目录从同一180万初始B图分别运行E1三轮主对照，exact为默认、PQ为对照，消融另定。旧执行器的首轮仅作历史对照，不混入新三轮。runtime、向量、GT、PQ码、图、快照、库及二进制不进入代码提交。

在准备好node3既有冻结输入后，最终复现顺序为 `python3 run_preflight.py`、`python3 run_gates.py`、`python3 run_perf.py`、`python3 summarize.py`；每个入口拒绝覆盖已存在的运行目录。预检默认目录为preflight-v2，首次历史尝试需显式另设namespace。本目录不能仅clone后在macOS运行完整实验。
