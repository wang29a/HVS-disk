# 核组复测补充：不合并不同 CPU 组

记录日期：2026-11-13，新的复测组开始之前。原协议的 72–75 核在中心计时期间出现高外部 CPU 负载，NUMA 验收正常但外部 CPU 阈值不通过；已拒绝的点不追认为正式结果。原组的接受点和拒绝记录全部保留。

资源约束仍为 NUMA3、四线程、BLAS 单线程。新复测在取得全局队列锁后，仅根据实际外部空闲采样，从 NUMA3 的物理连续四核块中选择一组，在开始查询计时之前固定；不根据 QPS 或方法优劣选核。运行期间核对真实 CPU affinity 与匿名内存 bind:3，原始 mask 不改写成旧核组。

新组写入 `review-20261113/cpu-recheck/`，重新测量中心 U1/S 与关键 SSD 格子的完整三轮，不复制原组的计时或 accepted 文件。只复用身份一致的确定性工作量、已有查询切分、训练选定参数；无重新 GT，无报告集调参。结果单独汇总，不能将旧组的个别接受点与新组拼成三轮。

如果 NUMA3 没有安静核组，空闲等待上限 180 秒后明确 deferred。测点超时及外部干扰最多三次，失败记录 pending，不接受无效计时，也不让一个计时点无限占队列。
