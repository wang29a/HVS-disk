# OpenImages 复核、中心过滤与密度扫描协议

冻结日期：2026-11-13，开跑前记录。数据和已有 GT 不变，不改写 mixed-α 查询的权重。新运行写入 `review-20261113/`，不覆盖 v1/v2 记录。

首先使用通过语义校验的 v2 构图器重建 OpenImages（456,699 节点、768+768 维），保持 R=40、L_build=200、C=750、8 线程、原始 ID 顺序及加权欧氏目标。源码与二进制身份核对 v2 校验记录。旧图与新图逐节点比较邻居 ID 集合、添加／删除边、共同边的区间并集、总区间宽度、共同边覆盖增减、平均度数、量化后固定权重点的活动边数量，以及入口变化。并行构图和新旧浮点编译设置可能带来结构差异，不能把全部差异都精确归因于一个分支。

以对称边差／边并集不超过 1%、平均度变化不超过 1%、共同边覆盖差宽度／旧总宽度不超过 1% 作为“小结构差异”的诊断阈值。该判定不保证性能不变；小差异时仍用少量冻结配置验证关键 SSD 工作点，再决定哪些旧结论可沿用。超过阈值则补关键 SSD 过滤开／关对照；不自动重跑完整六格。

构图期间，可在不同 CPU 上同时采集 Laion 2M、α=0.5 的确定性搜索工作量，不采用其计时。中心比较复用修正统一图、现有专用图、查询和 GT，无新图。先报告全图 float 与量化活动出度及边集合交集，再按相同入口、搜索器、查询切分，在 95% Recall@10 比较统一图开过滤 U1 和专用图 S 的展开量、距离评估、最终召回与正式三轮计时。正式计时等构图结束后运行。

相同候选池、候选顺序、阈值和预算下，剪枝谓词的等价性已有独立测试；完整图还受 GPS 候选、Pareto 次序、0.1 活动宽度阈值、全局 R 和反向插入影响，不能预设两图完全相等。中心展开比 S/U1 在 [0.8,1.2] 且量化活动出度比在 [0.8,1.2] 才称“接近”；否则暂停强度扫描，先核对边集合、轨迹和上述机制，不能自动判为代码错误或直接宣布二者等价。

OpenImages 当前可复用的是 1,000 条 mixed-α GT，已确认权重连续，未发现固定 0.1/0.5 GT。偏侧采用 [0.05,0.15)，居中采用 [0.45,0.55)，保留每条查询真实 alpha 与原 GT；沿用既有 500/500 划分，分别披露桶内样本量。不把这两桶写成固定 alpha。若桶内调参／报告各少于 20，标记样本不足并报告缺口，不静默合并数据。

结构差异明显时，在偏侧与居中桶分别对修正 Full 格式跑 SSD 过滤开／关。复用原 PQ、坐标、入口规则及 T|XY 原顺序，不加入 Starling 或共享缓存。导航／精排仍是历史六格的同一搜索器，采用 L×r 调参，只在训练查询选择工作量前沿，报告查询不挑最快点。在独立报告召回夹点内比较 95% Recall@10，不外推；冻结工作点后旧图也跑同样流程，以观察是否改变过滤方向。小结构差异时只跑原有冻结配置的旧／新 paired probes；没有覆盖目标就报告未覆盖，不据此恢复结论。

第 3 项核对分开记录：当前 v2 的直接剪枝及区间原语采用 <=；DEG 论文 §4.3 式(2)-(5) 使用严格 <，其闭区间案例及 §3.2 的表述还需区分边界约定，因此不写“完全按论文复现”。不在本次旧／新对照中静默改比较符。零系数遗漏、区间合并末项遗漏需分别用固定 commit 原源码证明；平方距离与欧氏目标错位则比对上游距离函数和迁移后的内核，证据未齐不先下归因结论。

第 4 项只在上述判断点通过后启动。固定 α=0.5，用直接邻域剪枝强度 rho 调节条件为 `d(center,p)<=d(center,q)` 且 `rho*d(p,q)<=d(center,q)`；rho>=1，增大时倾向保留更多边，其他参数不变。使用独立随机 100K 底库、无查询／GT 的构图 pilot，在预声明 rho 网格 1.0/1.025/1.05/1.1/1.2/1.4 中为目标平均度 24/30/35 选择最接近且不同的三个参数；rho=1 的现有 2M 专用图为约 18 度端点。pilot 只用于密度标定，不能保证全量精确命中目标；不根据报告延迟选择 rho。

全量曲线主报 95% 召回的展开量、拓扑及坐标提交页，附 PQ 评估与延迟。区分物理存储平均度和固定权重的活动平均度，统一图开／关过滤均定位。为隔离格式密度，主要页数对照统一使用 R=40、8 个区间槽的相同拓扑页容量；自然紧凑格式另列，不混入同一因果曲线。数据、PQ、入口、缓存、坐标布局、L×r 规则保持相同。不能把 DRAM 展开数或静态 trace 的唯一页数冒充 SSD 实测提交页。

若进入 SSD 强度扫描，Laion 2M 的 PQ 码从全量已有 PQ 按已验证 source_ids 映射提取，沿用原码本，坐标仅物化一次；不重训 PQ、不重算 GT。只在前置核验通过后申请实际输出容量。尚未运行的 pilot、全量图及 SSD 点不得记为已完成。
