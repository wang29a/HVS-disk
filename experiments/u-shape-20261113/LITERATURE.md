# 权重专用图：文献判断

核查日期：2026-11-13。结论是：**专用图与按 α 路由已有直接先例，本轮可继续作因果诊断，不能将最简路由包装成新方法。**

DEG §5.1 已有五权重的专用 HNSW Oracle，Overlay 还把分权重图的边合并后按查询 α 路由到相应子图；§5.2.2 报告 DEG 与 Oracle 的性能接近。这与拟议阶段二／三直接相关，但不是同一搜索器、等边预算下的展开数与 SSD 页成本实验。[DEG 原文 §5.1–5.2](https://arxiv.org/html/2502.07343v1#S5.SS1)

ACTIVE 明确讨论偏好专用多索引与统一 Pareto 图，静态评估比较 MR 和 DEG。其 Laion 设置另指出，构建候选预算 200 时平均出度约为 R/2，因此改用 400；这提示本实验必须核对真实平均度数，不能把同名 R 视作相同边预算。[ACTIVE v2 §6.1](https://arxiv.org/html/2610.35751v2#S6.SS1)

| 工作 | 已有内容 | 与本轮的关系 |
|---|---|---|
| [MUST，ICDE 2024](https://arxiv.org/abs/2312.06397) | 模态权重学习、融合邻近图 | 权重感知图并非新问题；本轮不复现其整套框架 |
| [GEM，2026](https://arxiv.org/abs/2603.20336) | 向量集合上的原生图与分簇导航 | 集合级相似度，不能直接当作两个固定属性空间的 α 专用图 |
| [MV-HNSW，2026](https://arxiv.org/abs/2604.02815) | 原生多向量节点及集合级图搜索 | 也不等同于查询可变的双空间加权欧氏目标 |
| [MUVERA，v2 2026](https://arxiv.org/abs/2405.19504v2) | 用定长编码近似多向量集合相似度 | 可说明任务边界，不能替代当前三权重对照 |

本次查到的最接近先例是 DEG Oracle/Overlay；尚未在这些已核查内容中找到“同一指针搜索器、精确导航、统一／专用图、等召回展开数”的完整因果对照，也未确认相同预算下的 SSD U 形页代价已经被系统报告。这里的“未找到”只限于本次检索和阅读范围，不证明不存在。

因此文献判断点已经改变后续定位：阶段二回答“当前图是否存在可挽回的权重适配损失”；阶段三只有在 SSD 实测显示额外拓扑、坐标复用和缓存预算值得时才继续。不能从 DRAM 展开下降直接推出 SSD 加速，也不能预设 SSD 上解决代价更低。若只有固定 α 建图和路由，没有进一步的存储设计证据，就作为已有方法对照，不单独建立新论文主张。

检索范围包括 DEG、ACTIVE 全文相关章节及其 baseline 引文，并以 query weights、dual-vector、hybrid vector、weight-specific index 等词检索 2025–2026 工作。MUST、GEM、MV-HNSW、MUVERA 此处按作者摘要／任务定义筛选，没有宣称完成其代码复现或全部实验核对。
