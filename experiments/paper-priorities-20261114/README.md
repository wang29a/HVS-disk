# 四项论文补测：冻结协议

2026-11-14冻结。顺序为OpenImages配对补齐、Laion无旁表统一图、中心度数扫描、加权双索引异常分析。前两项先产出；本队列不启动OpenImages全量多图对比，不重建已有统一图／中心图，不重新计算GT。后续协议调整只在本文末尾追加原因。

## 1. OpenImages 新图过滤配对

复用 `u-shape-20261113/review-20261113/cpu-recheck` 的独立核组、训练冻结配置和已验收测点。CPU80–83、NUMA3、四线程、BLAS单线程；原mixed-alpha偏侧[0.05,0.15)和居中[0.45,0.55)，报告查询分别59和43条，目标95% Recall@10。旧／新图、开／关过滤各配对三轮，pages和compute规则分别报告。不得合并原72–75核组。

原70个有效点含中心精确导航等记录，本次只复用SSD相关点，补缺的5个点。所有原记录只读，新结果写在本实验runtime下。补点仍执行原外部CPU、NUMA和设备写流量验收，最多三次噪声重试；超时／缺点明确记录，不用不完整均值下结论。补点跨时间，另在旧／新偏侧开过滤的两个夹点各测一轮锚点。锚点相对原三轮均值若偏离超过10%，不混合时间批次，另跑完整旧／新8臂三轮新队列。新队列可在NUMA3内按外部空闲选择四核，选择与QPS无关。

最终分别计算每个图／分桶的开过滤延迟÷关过滤延迟、总提交页及拓扑／坐标分项、PQ评估数。仅使用同一规则、同一核组、完整三轮的95%插值均值；p95不插值。报告正负方向，不预设“过滤一定不划算”。

## 2. 关过滤且不加载区间旁表

复用多图实验原执行器、统一图compact拓扑、同一坐标、PQ和500条报告查询。派生manifest中统一图的sidecar路径设为`-`、slots设为0；不改图文件，不通过修改meta隐藏仍然读取的区间。原执行器该分支不会打开、分配或解析旁表，关过滤搜索不调用active。运行输出须满足sidecar_bytes=0；若strace可用，在非计时检查中核对没有打开ranges.bin。

α=0.1/0.3/0.5/0.7/0.9，使用先前加权页成本规则冻结的95%召回夹点，完全不看新延迟调参。不加载版与原加载版在全部500条报告查询上的展开批次、精排候选、返回ID／距离须字节一致。正式只做一轮10秒工作点测量，配套原加载统一图和对应权重单张专用图作同时段参照；不冒称三轮正式结论。统一图与专用图各用原先独立冻结配置。

报告延迟、QPS、实际提交页、峰值RSS、PQ编码与旁表字节数。内存相当的预声明标准为无旁表统一图峰值RSS／对应单张专用图峰值RSS在[0.90,1.10]；超出则如实说明，不预设证明成功。延迟以完整单轮报告，资源验收失败有限重试，不挑最快一次。返回距离沿用独立float64相对误差≤5e-6核验。

## 3. α=0.5 专用图度数扫描

只修改隔离固定目标剪枝器的强度rho，保留现有LE平局政策、开方融合、候选构造和入口政策。覆盖条件为`d(c,p)<=d(c,q) && rho*d(p,q)<=d(c,q)`，rho作用于已融合的欧氏距离，不是平方距离；rho=1必须与已验证固定剪枝成员一致。R=40、L=200、C=750；固定α=0.5。

先在2M底库中按seed=20261114确定性随机取100K节点，只用于构图出度pilot，不使用查询／GT。pilot网格rho=[1,1.025,1.05,1.1,1.2,1.4,1.8,2.0]，利用平均度数选择三个不同的rho，分别尽量靠近24、30、35；现有rho=1、均值18.613898的2M中心图直接复用，总计四张专用图。不在报告查询或延迟上选择rho。若最终2M出度没有覆盖统一图33.1324895，不外推、不额外自动补图，判为同度数问题尚未覆盖。

构图最多8核NUMA3，先做独立参考剪枝和rho=1实际成员等价检查。所有搜索使用同一统一图入口、相同坐标／PQ，compact R40格式164B、49节点/页；统一图关过滤且无旁表是主参照。主图包括精确指针DRAM导航下95%召回的展开数／距离评估数对平均出度，以及PQ+精排SSD下95%召回的展开数、拓扑／坐标提交页；避免把两个搜索器的工作量混为同一曲线。

精确指针导航固定L网格[20,30,40,60,80,100,120,160,240,400,800,1600]，跳过小于共同入口数的档位；训练与报告分开。PQ搜索沿用原八档L和六档候选预算，只按训练集页数冻结前沿，报告集首个实际95%夹点内插值，三轮正式SSD计时；不选报告最低延迟。现有图的工作量可用身份一致的新compact统一格式重新测量，不重建原图。

事前判读：专用图的实测度数曲线夹住统一图度数时，按度数在相邻两张专用图的matched-recall工作量间线性插值，并同时列原始两点。若专用图展开数和拓扑页都至少减少10%，支持中心统一图存在可改善的图级工作量；若两者均在±10%以内，未发现中心等度数优势；一好一坏或介于阈值之外则为权衡，不能强定方向。若只在PQ路径不同、精确导航接近，优先解释为近似／精排因素，不能归因于统一图本身。仅中心权重的扫描不能证明整条U形由图造成，U形继续作为观察。

## 4. 加权双索引异常

度数扫描之后读取已完成的α=0.3等量／加权tune、frozen、report和三轮计时；不重新运行实验、不改预算。列出95%报告夹点的L、kx／ky、分配规则、训练与报告召回、插值权重、展开／PQ／精排与页数，检查训练规则是否按预声明工作量执行、是否有未被选择的支配配置、报告前沿是否跳跃。对其他权重作已有记录的参照。

若只能定位到有限网格／工作量代理选择的权衡，不能声称加权架构天然更差；若仍查不清，论文主对照使用等量版，加权版放入如实报告的敏感性结果。没有授权扩大搜索网格或按报告延迟重新挑最优配置。
